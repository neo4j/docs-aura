= Aura Assistant
:description: Learn how Aura Assistant helps you get started with Neo4j Aura.

Aura Assistant is an in-console chat assistant that helps you get started with Neo4j Aura.

You can use it for the following, and more:

* *Writing Cypher queries:* Aura Assistant suggests Cypher queries. 
To run a query against your database, select `Run` in the chat.
Changes made by those queries remain in your database after the chat ends.

* Aura Assistant can *load a sample graph model* and walk you through running the import.

* Aura Assistant can help you *explore industry use cases* and explain the model's nodes and relationships.

* *Connect and switch between instances:* Aura Assistant can open the connection dialog. 

For Aura Assistant to be available, an xref:user-management.adoc#_organization_level_roles[organization admin] must enable *Generative AI assistance* under xref:visual-tour/index.adoc#org-settings[organization settings].

It connects to your Aura database as your user; It does not use its own user or a service account, so it has the same permissions to read and write to a graph as your user.

Aura Assistant asks for your permission before performing an action, such as connecting to a database, inspecting the schema, or running a query.


Each chat is a separate session. 
Conversations are not carried over to future sessions and are not retained by Neo4j.
Aura Assistant sends data to a third-party provider. 
For more information, see link:https://neo4j.com/docs/reference/license/onboarding-assistant/[How Neo4j Aura Onboarding Assistant uses AI models]
