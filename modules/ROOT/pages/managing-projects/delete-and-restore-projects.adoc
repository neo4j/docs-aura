= Delete and restore projects

== Delete a project

Deleting a project stops billing and resource usage immediately.

Deleting a project starts a 30 day recovery window. 
During this window, the project can be restored at any time and no data is lost.
If the recovery window expires without a restore, the project and all associated data are permanently destroyed.

=== Required roles

* `Project Admin`
* `Organization Owner`
* `Organization Admin`

=== How to delete a project

[.tabbed-example]
====
[.include-with-Aura-console]
=====

* Go to xref:visual-tour/index.adoc#_project_settings[Project settings] -> *Delete Project*

* Select *Delete Project*.

* A warning modal appears.

* Type the name of the project to confirm, then select *Confirm Deletion*.

=====
[.include-with-API]
=====

[source]
----
DELETE organizations/{organizationId}/projects/{projectId}
----

=====
====

== Recover a deleted project

A project can be restored within the 30 day recovery window that begins when the project is deleted.
Aura instances will automatically resume. 
Compute billing will resume once the resources are active.

[IMPORTANT]
====
For Graph Analytics Users: Because Graph Analytics sessions are compute-based, they are permanently terminated when a project is deleted. If you restore a project, you will need to provision a new GDS session.
====

=== Required roles

* `Organization Owner` 
* `Organization Admin`

=== How to recover a deleted project

[.tabbed-example]
====
[.include-with-Aura-console]
=====

* Go to xref:visual-tour/index.adoc#_organizations[Organization Settings] -> *Recover deleted projects*
* Locate the project you wish to recover.
* Select *Restore Project*.

=====
[.include-with-API] 
=====

[source]
----
POST organizations/{organizationId}/projects/{projectId}/restore
----

=====
====

.Downstream Resource Behaviour Matrix
[cols="2,3,3,3", options="header"]
|===
| Resource | Deletion Requested | Project Restored | Project Deleted

| Instances (Aura DB)
| *Pause:* Compute is halted immediately to stop hourly compute metering. Storage volumes are retained.
| *Resume:* All instances within the project are resumed.
| *Destroy:* Storage volumes are permanently deleted. Backups remain until the backup retention period ends.

| Graph Data Science (Sessions)
| *Terminate:* GDS sessions are terminated to stop compute billing.
| *No Action:* Users must manually provision a new GDS session.
| *Delete:* Remove all data.

| GenAI (Agents)
| *Suspend:* Agent endpoints are disabled.
| *Enable:* Agent endpoints are re-enabled.
| *Destroy:* Agent configurations are deleted.

| Dashboards
| No action
| No action
| *Delete* all dashboards associated with instances in the deleted project.

| API
| *Stop:* Existing data APIs and associated billing are stopped.
| Restore to previous setup.
| *Delete* all Data APIs associated with instances in the deleted project.

| Saved Cypher
| No action
| No action
| *Delete* all saved Cypher and tools data associated with instances in the deleted project.

| Data Importer / Import Jobs
| *Terminate:* Ongoing import jobs; prevent future jobs from starting.
| No action
| *Delete:* All data sources and import job history.
|===
