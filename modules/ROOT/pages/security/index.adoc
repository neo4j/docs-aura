= Security
:description: This section covers important security aspects in Neo4j.

This section describes how to ensure security of your Neo4j Aura instances.

== Identity 

Protect access from the start.

* Log into the console/project/instance with SSO linked to Aura Role-Based Access Control (RBAC)
* Multi-Factor Authentication (MFA)

== Network 

Control how traffic reaches your databases.

* IP filtering limits access as you get your robust security set up. 
* Private Link creates a secure tunnel for your data.

== Platform 

Reduce operational overhead with managed security.

* Automatic updates and security patching.
* Managed infrastructure.

== Data protection 

Keep data encrypted and under your control.

* Customer-Managed Encryption Keys (CMEK)
* Remove inactive members from an organization automatically.

== Compliance 

Meet government requirements with confidence.

* For more information, visit https://trust.neo4j.com to learn about Neo4j Aura's security posture and request access to additional security documentation.
