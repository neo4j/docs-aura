= Billing alerts

Create an alert to receive an email notification when a selected billing account reaches an amount or threshold you define.
Whenever the consumption, cost or credit balance reaches a defined threshold, an email alert is sent to Organization Owners and Organization Administrators.

[IMPORTANT]
====
The alerts are not triggered immediately when a threshold is reached, as it can take up to 24 hours for the alert to be evaluated.
It is recommended to set the target amounts and thresholds proactively, below the amount that will actually affect you. 
====

Alerts are reset monthly after each invoicing cycle on the 1st of the month.

You can set up one alert per type per billing account per type of alert.
Trigger the alert for up to 4 amount thresholds.

== Required roles 

Organization Owners and Organization Administrators can set up alerts, receieve alerts, and manage custom spend and credit balance alerts directly in the Aura console. 

== Billing alert types

You can create the following alert types:

* *Consumption* - Triggered when month-to-date consumption reaches the target amount, before any credits are applied.

* *Cost* - Triggered when month-to-date actual cost reaches the target amount. 
This is the remaining amount due after any credits were applied, and reflects your actual financial exposure.

* *Credit balance* - Triggered when the remaining credit balance falls below a specified threshold. This is independent from consumption or cost alerts.

== Create an alert

. Go to *Billing* in the xref:visual-tour/index.adoc#org-settings[Organization settings].
. Select the *Alerts* tab.
. Select *New Alert*.
. Enter a name for the alert.
. Select the funded *Billing Account* to monitor.
. Choose an alert type:
+
** *Consumption*
** *Cost*
** *Credit balance*
. Set a start date and, optionally, an end date.
. For consumption and cost alerts, enter a target amount in ACUs (Aura Consumption Units).
. Optionally, add up to four additional thresholds as values or percentages.
. Activate and save the alert.

== Editing and deactivating alerts

From the *Alerts* dashboard, you can edit threshold values or toggle alerts between active and inactive states. 
Deactivating an alert pauses notifications without removing the configuration.
