== LLMs and regions

Document Intelligence uses different LLM models in different regions.
All processing is done in the same cloud provider and in the closest region to the target instance, if the same region is not available.
Only non-EU and non-US regions are routed to `global`.

== Permissions

The workflow in Document Intelligence uses an internal service account to connect to your target instance.
The service account has the required permissions for the job to run and these may escalate the permissions granted the user.
This is the full list of permissions required for the service account:

[source]
----
   - access: {}
    - showConstraint: {}
    - showIndex: {}
    - indexManagement: {}
    - match: {}
    - executeProcedure:
        names:
          - "db.labels"
          - "db.relationshipTypes"
          - "db.schema.visualization"
          - "db.schema.nodeTypeProperties"
          - "db.schema.relTypeProperties"
          - "apoc.meta.schema"
          - "db.index.fulltext.queryNodes"

----
