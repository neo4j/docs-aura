= Activity feed
:description: This page describes the activity feed in the Neo4j Aura console.

The activity feed allows organizations and especially administrators to track activities and events in the console.
This feature provides a detailed record for all deployments that cannot be turned off.
It helps teams detect unusual behavior in real time as well as aiding organizations in maintaining audit trails for regulatory compliance reasons.

The activity feed follow a structured _JSON_ format can be exported in both _.CSV_ and _JSON_ formats to allow integration with SIEM (Security Information and Event Management) solutions.
The Activity feed tracks events on both Organization and Project level.

== Captured events

The events captured in the feed fall into the following categories:

* *User account changes* - User invitations, removals, modifications.
* *Privilige management* - Grants, revocations, role assignments.
* *Instance actions* - Creation, alteration, deletion.
* *Configuration changes* - Inserts, updates, deletes.
* *System events* - Database pause/resume, backup creation/restore.


== Structure

The exportable activity logs are structured in a _JSON_ format that is consistent with audit log standards and parsable programmatically and thus SIEM compatible.

Each event record includes:

* *Unique Event ID*
* *Organization ID*
* *Timestamp* in UTC, both in Unix Epoch and ISO 8601-style
* *Project ID*
* *Project Name*
* *User ID*
* *User Email*
* *Status*
* *Action ID* that maps to the type of action
* *Action Name* that describes the type of action
* *IP Address* where the action was initiated
* *Payload*

Note that not all items included in the _JSON_ file are surfaced in the UI.

== Access the Activity feed

The *Organization-level* activity feed is accessed via the top-level *Organization* menu.

[.shadow]
.Organization-level activity feed
image::org-level-activity.jpg[width=600]

This view is available to organization owners and admins and shows all activity across the entire organization.

The *Project-level* activity feed is accessed via the *Project* menu from the sidebar.

[.shadow]
.Project-level activity feed
image::project-level-activity.jpg[width=400]

This view is available to project admins and shows logs specific to a project, which offers a more granular overview than the org-level.

== Filter and export

You can filter the activity feed directly in the console and display the results.
The results can be filtered by *date and time*, *status*, *user*, *action*, and *IP address*.
Use the -> arrow to see the caputred details for the activity listed.
Additionally, you can control which columns that are displayed with the table symbol (all the way to the right in the table header).

[.shadow]
.Filter activity feed
image::activity-feed.jpg[width=full]

The activity feed can be exported either in a _JSON_ format or as _CSV_.
This feature allows up to the last 30 days of activity to be exported and offers the same filtering options.
Use the *Export* button to select which format and which filters (or none) you want to apply for your export.
