== Pause an instance

Pausing a Neo4j instance temporarily stops the database, which means:

* No connectivity: Any applications or users trying to connect to the instance won't be able to run queries or retrieve data until the instance is resumed.

* No processing: The database won't process any operations or transactions while it is paused.
Any ongoing operations are halted.

* Data is preserved: Your data remains safe and unchanged while the instance is paused.
You may export a backup of your data within its exportable period. 
When you resume the instance, you can pick up right where you left off.

You can pause an instance when not needed and resume it at any time.

When you pause an instance, Aura performs a backup operation behind the scenes.
It can take a while to pause, depending on your instance size, because Aura is creating the backup.

[NOTE]
====
You cannot manually pause an AuraDB Free instance; they are paused automatically after 72 hours of inactivity.
====

[NOTE]
====
Paused instances run at a discounted rate compared to standard consumption, as outlined in the confirmation window.
You can pause an instance for up to 30 days, after which point Aura automatically resumes the instance.
====

[.tabbed-example]
====
[.include-with-API]
=====

/instances/{instanceId}

=====

[.include-with-UI]
=====

Use the *Pause* button on the instance card.
After confirming, the instance begins pausing, and a play button replaces the pause button.

== Resume a paused instance

When you resume an instance, Aura restarts the instance and restores it from the backup. 
Resuming the instance can take a few minutes to a few hours, depending on its size.

[WARNING]
====
Aura Free instances do not automatically resume after 30 days.
If an Aura Free instance remains paused for more than 30 days, Aura deletes the instance, and all information is lost.
====

[.tabbed-example]
====
[.include-with-API]
=====

Pause: POST https://api.neo4j.io/v1/instances/{instanceId}/pause. 
Resume: POST .../instances/{instanceId}/resume. 
Poll GET .../instances/{instanceId} for status: paused or running.
POST /v1/instances/{instanceId}/pause
POST /v1/instances/{instanceId}/resume
Poll GET /v1/instances/{id} — check status field

|===

=====

[.include-with-UI]
=====

Resume a paused instance with the *Play* button on the instance card.
After confirming, the instance begins resuming.

== Delete an instance

Deleting an instance removes all associated snapshots, so they cannot be used to backup and restore data. 

If you may need the data later, xref:/managing-instances/backup-restore-export.adoc#_on_demand[take a snapshot] and export and save it on your computer, before deleting the instance.

[WARNING]
====
There is no way to recover data from a deleted Aura instance, including snapshots.
If you may need the data later, export a snapshot before deleting the instance.
====

[.tabbed-example]
====
[.include-with-API]
=====

DELETE /v1/instances/{instanceId}
No request body required
Reset to blank has no API equivalent — console only

https://neo4j.com/docs/aura/platform/api/specification/#/instances/delete-instance-id

|===

=====

[.include-with-UI]
=====

Delete an instance using the trashcan icon on the instance card.
Type the exact name of the instance (as instructed) to confirm your decision, and select *Destroy*.
