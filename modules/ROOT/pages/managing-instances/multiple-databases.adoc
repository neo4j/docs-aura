= Multiple databases
:description: This page describes multiple databases within an Aura instance and how to create and connect to a database. When connecting, select the target database using the connection bar or driver configuration.

label:AuraDB-Business-Critical[]
label:AuraDB-Virtual-Dedicated-Cloud[]

== Overview

Create and manage multiple databases within an AuraDB instance using the Aura Console or the Aura API.
An instance has its own compute and storage, and the databases run within the instance.
Scale from a few to 500 databases within one instance.

If your instance supports multiple databases, they are listed in Instance details → Databases.

== Use cases

Use multiple databases when you need clear separation of data within a single instance, without managing multiple instances.

* Lower administrative overhead compared to running multiple instances
* Development and test environments
* Different teams or features working in the same instance
* Faster to create and remove than separate instances

== Enable multiple databases

[IMPORTANT]
====
You must enable multiple databases during instance creation.  
This setting cannot be changed later.
====

== Create a database

To create a database, connect to your instance.  
From the more menu (three dots), select *Inspect*, then go to the *Databases* tab.

Select *Create Database* to add a new database.  
A default name is generated automatically (for example, `293fd870`).
The `DEFAULT` database cannot be deleted.

== Manage multiple databases

Access database details from *Inspect > Databases* within a running instance.
Use the search bar to search for a database by name.

The table shows:

* Database names (the default database is labeled)
* Number of nodes and relationships
* Status (for example, `RUNNING` indicates the database is online and ready to accept connections.)

Use the more menu (*...*) for database-specific actions.

For more information about inspecting an instance's details see xref:managing-instances/instance-actions.adoc#_inspect_an_instances_details[inspect an instances details]

== Limits (RAM and maximum databases)

All databases share the instance’s compute and memory resources.  
The maximum number of databases depends on the memory size (RAM) of the instance.  

[cols="1,1", options="header"]
|===
| Available Instance Memory | Maximum Databases

| 32GB
| 160

| 64GB
| 320

| 128GB
| 500

| 256GB+
| 500
|===

== Supported features

Multiple databases are supported across Aura tools.
For working with multiple databases, see the following documentation:

* xref:managing-instances/backup-restore-export.adoc[Backup, export, and restore] Take snapshots of your databases.
* *Explore and Query*: When connecting, select the target database using the connection bar.
* *Metrics*: Switch between databases using the Database dropdown in Metrics.
* *Import*: Select both the instance and the target database when running an import.

== Unsupported features

Some features are not available for multi-database instances:

* Custom database naming or renaming.
* Pause and resume for instances or individual databases.
* Databases cannot be created using Cypher database management commands.
