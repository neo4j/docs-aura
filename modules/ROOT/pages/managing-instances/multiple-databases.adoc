== Overview

AuraDB Business Critical and AuraDB Virtual Dedicated Cloud support multiple databases within an AuraDB instance (DBMS).  
You can create and manage databases using the Aura Console or the Aura API.

=== Use cases

Use multiple databases when you need clear separation within a single Aura instance.
Multiple databases keep data organised within a single instance, without the overhead of managing multiple instances.

* Less administrative overhead compared to running multiple instances
* Development and test environments
* Different teams or features working in the same instance

== Max number of databases

All databases share the instance’s compute and memory resources.  
The maximum number of databases depends on the memory (RAM) of the instance.  
For example, a 4GB instance supports up to 4 databases.

== Enable multiple databases

[IMPORTANT]
====
You must enable multiple databases during instance creation.  
This setting cannot be changed later.
====

[.shadow]
.Multiple databases toggle
image::multiple-databases/multiple-databases-toggle.png[]

To create a database, connect to your instance.  
From the more menu (three dots), select *Inspect*, then go to the *Databases* tab.

Use *Create Database* to add a new database.  
A default name is assigned automatically (for example, `293fd870`).

The `DEFAULT` database cannot be deleted.

.Create database

== Manage multiple databases

Access database details from *Inspect > Databases* within a running instance.

The table shows:

* Database names (the default database is labeled)
* Number of nodes and relationships
* Status (e.g. `CREATING`, `RUNNING`)

`RUNNING` indicates the database is online and ready to accept connections.

Use the three-dot menu for database-specific actions.  
Use the search bar to filter by name.

== Backups

Backups are managed at the database level.

From *Inspect > Backups*, use the *Select Database* dropdown to choose a database.

== Database administration

Aura manages the `system` database and handles administrative routing automatically.  
The system database is used for RBAC and SSO configuration.  
You do not need to interact with it.

=== Explore and Query

Use the connection bar in Explore and Query to select the database you want to work with.

=== Metrics

Metrics support database-level selection and charts.  
Integrations provide per-database metrics.
In *Metrics > Database*, use the dropdown to switch between databases.

=== Import

When running an import, select both the instance and the target database.

== Limitations

Some features are not yet available for multi-database instances:

* Custom database naming or renaming
* Pause and resume for instances or individual databases

Databases cannot be created using Cypher database management commands.  
Use the Aura Console or API instead.
