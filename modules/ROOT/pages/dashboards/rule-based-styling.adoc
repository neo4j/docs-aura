= Rule-based styling 

Rule-based styling is more fun than its name suggests. 
Add styling rules to highlight important chart values with color, making tables easier to scan and interpret at a glance. 

When multiple rules are defined they are executed in order, and you can drag and drop them to change the priority.

This example uses the Northwind dataset, and rule-based styling to highlight stock levels.

A really simple one shows units in stock as green if they are above 115. 

=== Apply a gradient

This example applies progressively darker shades of green to products with higher stock levels, making it easy to identify the most well-stocked products at a glance.

Create a table:

[source,cypher]
----
MATCH (p:Product)
RETURN
  p.productName AS Product,
  p.unitsInStock AS `Units in stock`
ORDER BY `Units in stock` DESC
LIMIT 10
----

Select *Styling*

* Type = `cell`
* Column = `units in stock`
* Condition = `Greater than`
* Value = `110`
* Select = *Range*
* Background = Range 

** Minpoint = 110 #abd9af
** Midpoint = 115 #65ee72
** Maxpoint = 120 #579380

* Text = `Single` (#0829f5)

* Select *Apply* to apply the rule to the current visualization.
