= Rule-based styling 

Make tables easier to scan and interpret at a glance by adding styling rules to color important values.
Styling updates dynamically as your data changes.
Apply styling to cells, rows, and text, or use color gradients to emphasize numeric values.

To create a styling rule open a *Table* visualization > Select the *Styling* tab > Select *Add* > Configure your rule > Select *Apply*. 

You can create multiple styling rules. 
Rules are executed from top to bottom, so drag and drop them to change their priority.
