= Rule-based styling 

Rule-based styling is more fun than its name suggests. 
Add styling rules to highlight important chart values with color, making data easier to scan and interpret at a glance.
Rule-based styling is currently available for table visualizations. 
Colors update automatically as your data changes.
You can style cell or row backgrounds, text color, and number values using gradients.

To create a styling rule open a *Table* visualization > Select the *Styling* tab > Select *Add* > Configure your rule > Select *Apply*. 
You can create multiple styling rules. 
Rules are executed from top to bottom, so drag and drop them to change their priority.

This example uses the Northwind dataset and rule-based styling to highlight stock levels.
It uses two styling rules:

* Highlight values greater than `110` with a green background gradient. Color all the text in the table in blue to make the values stand out.
* Highlight rows with values less than or equal to `110` in red to make low stock levels easy to spot.
