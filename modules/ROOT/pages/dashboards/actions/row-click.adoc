= Row click

This example uses the crime database to list all crimes in one area
Add multiple crime IDs to a filter selection.

/* list all crimes in one area */

[source,cypher]
----
MATCH (c:Crime)-[:OCCURRED_AT]->(l:Location)-[:LOCATION_IN_AREA]->(a:AREA)
RETURN c.id AS CrimeID, c.type AS CrimeType, c.date AS CrimeDate, c.last_outcome AS LastOutcome, a.areaCode AS AreaCode
ORDER BY c.date
----

== Actions 

TRIGGER row select
UPDATE PARAMETER new parameter $row
TO CELL VALUE CrimeID
(Adds the selected rows' CrimeID values to $rowSelect)
