= Report actions
:description: Use dashboard actions to connect cards, set parameters, and navigate between pages or external link URLS in a Neo4j dashboard report.

*Use actions when you want selecting a value to both update a parameter and trigger an action.*

== Overview

When a value is selected in the dashboard, an *Action* sets it as the `$input` parameter.
Cypher queries reference this parameter, so the visualizations update dynamically based on the selection.

You can use actions to:

* Set a parameter
* Set a parameter and navigate to a URL
* Set a parameter and navigate to a page within the dashboard

An action is event-driven.  
When you select a value (e.g. by clicking a value in a table) the Action updates the associated parameter.  
Any card that references that parameter responds immediately.

== Example

This example uses the Northwind dataset.

* The example starts with the default *Main page*.
* Add a second page called *Employee info*.
* Use an Action on the *Main page* to set a parameter and navigate to *Employee info*.

Create the *Employee info* page first, because the Action will navigate there.

1) On the *Main page*, create a Cypher card that returns each employee’s name, number of orders, and total revenue.

[source,cypher]
----
MATCH (e:Employee)-[:SOLD]->(o:Order)-[orders:ORDERS]->(:Product)
WITH
  e,
  sum(coalesce(orders.quantity,0) * coalesce(orders.unitPrice,0)) AS revenue,
  count(DISTINCT o) AS ordersCount
RETURN
  e.firstName AS EmployeeName,
  ordersCount AS Orders,
  round(revenue * 100) / 100.0 AS Revenue
ORDER BY Revenue DESC
----

2) Add an Action to the EmployeeName column

. In the report actions panel, set *When* to *Cell click*.
. Set *On* to *EmployeeName*.
. Set the *EmployeeName* parameter to *EmployeeName*.
. Set *Navigate to page* to *Employee info*.

3) Use the parameter on the Employee info page

On the *Employee info* page, add a Cypher card that reads the parameter and returns details for the selected employee.

[source,cypher]
----
MATCH (e:Employee)
WHERE e.firstName = $employeename
RETURN 
  $employeename AS employeename,
  e.notes AS EmployeeDescription
----
