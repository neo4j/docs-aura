= Filters
:description: Use parameters in your dashboards to further customize queries or use them in filters for node and relationship properties.

* A **parameter** is a placeholder value used inside a query.
* A **filter** is a dashboard widget — a dropdown — that lets someone choose what value a parameter should have, without editing the query directly.

Filters are the main way to change the default parameter values.
Filters also allow others to configure parameter values.

A dropdown lets you choose the value you want to insert into the parameter.

[NOTE]
====
Filters are specific to Dashboards and are extremely useful - especially now that there's actions that can set a parameter value and navigate to a different tab.
====

Normally you should always go by filter and not necessarily create a parameter on your own.
But it depends if you want to expose it to the dashboard user. 
You might create a dashboard and share it with `view` permissions with other users. 
And then you might want to have some parameters that hold values that you use in your queries - but the `View only` users never see them.

They can be created in two ways:

* Add a filter and parameter
* Link a parameter to a filter

== Example 1: Add a filter and parameter

Create a filter to see which companies are based in a city, with the default set to London.

.Example: Filter to see which companies are based in a city with the default showing London
[.shadow]
image::dashboards/parameters-and-filters/filterexample.png[]

=== Step 1: Define the filter

. On the **Dashboards** page, select **Add filter**.
. Choose filter type `Node property`.
. Select the label `Customer`.
. Select the property `City`.

In the right pane, you can see a preview of how your filter will look and also interact with it.

=== Step 2: Link the parameter

. A parameter named `$customer_city` is created automatically.
. Set the default value to `London`.
. Select **Save**.

=== Step 3: Add a card

Paste the following query into the Cypher input, then select *Save*:

.Cypher query for a table which displays customers within a city
[source,cypher]
----
MATCH (n:Customer)
WHERE n.city = $customer_city
RETURN n.companyName AS `Company name`
----

.Cypher query for a table which displays customers within a city
[.shadow]
image::dashboards/parameters-and-filters/london-cypher-query-example.png[]

Changing the city in the filter updates the table dynamically.

.Filter and table showing customers located at the selected city
[.shadow]
image::dashboards/parameters-and-filters/customers-located-at-selected-city.png[]



== Example 2: Link a parameter to a filter

=== Step 1: Open the parameters drawer `{}`

.How to access the parameters drawer
[.shadow]
image::dashboards/parameters-and-filters/drawer.png[]

=== Step 2: Add a parameter

. Select **Add**.
+
. In the dialog, enter a parameter name `unit_param`, select the value type `integer`, set the default value to `4`, then select **Save**.
+
.How to set up a parameter with a number value of 4 named "unit_param"
[.shadow]
image::dashboards/parameters-and-filters/add-parameter.png[width=500]

=== Step 3: Add a card 

. Add a card.
+
. Paste the following Cypher into the card, then select **Save**:

.Cypher query for a table which displays products with a certain number of units in stock
[source,cypher]
----
MATCH (p:Product)
WHERE p.unitsInStock = $unit_param
RETURN p.productName AS product, p.unitsInStock AS units
LIMIT 10
----

.Using a parameter in a query to display products with a certain number of units in stock
[.shadow]
image::dashboards/parameters-and-filters/inquery.png[]


=== Step 4: Define the filter

. Add a filter.
. Select the filter type `Node property`.
. Select the label `Product`.
. Select the property `unitsInStock`.

=== Step 5: Link the existing parameter

. Select **existing parameter**, then select `$unit_param`.
. The default value is `4` (changing it overrides the parameter default).
. Select **Save**.


The parameter and filter are now connected.

Selecting a value from the dropdown updates the parameter `$unit_param` and updates the table.

.Selecting a new value for the unitsInStock filter
[.shadow]
image::dashboards/parameters-and-filters/filter-and-card.gif[]

== Rename a filter

To rename a filter:

* Hover over the filter widget
* Select *Edit* 
* In the full screen window top left double click the filter name
* Edit it as you like then press enter or the tick icon to save it
